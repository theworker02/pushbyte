# pushbyte

Push structured JSON byte payloads without a heavyweight toolkit.

**Site:** https://theworker02.github.io/pushbyte/

## Install / run

```bash
git clone https://github.com/theworker02/pushbyte.git
cd pushbyte
node src/cli.js
node --test
```
